# Digi-Pet
### A Gamified Coding Education Platform

Digi-Pet is an interactive educational platform designed to help
aspiring software engineers improve their problem-solving skills
through structured coding challenges and gamification.

Inspired by Duolingo's progression system, Digi-Pet encourages
consistent practice through personalized learning paths,
gradual difficulty progression, and an interactive digital
cat companion.

## Project Overview

Many aspiring software engineers struggle with maintaining
consistent coding practice due to a lack of motivation,
unclear learning paths, and the overwhelming number of
problems available on traditional coding platforms.

Digi-Pet aims to address these challenges by providing
a structured and engaging learning environment.

The application features a small animated cat positioned
in the bottom-right corner of the user's screen.

This virtual companion motivates users through daily reminders,
encouraging messages, and interactive feedback.

## Core Features

### Interactive Digital Cat

A virtual cat companion that encourages consistent coding practice.

Features include:
- Daily coding reminders
- Motivational messages and programming facts
- Celebrations upon completing challenges
- Interactive animations and feedback

### Progression-Based Learning

A structured learning path inspired by Duolingo.

Users progress through coding challenges organized by
data structures, algorithms, and difficulty levels.

Example progression:

| Stage | Topic | Difficulty |
|-------|-------|------------|
| 1 | Arrays | Easy |
| 2 | Arrays | Easy |
| 3 | Arrays | Medium |
| 4 | Arrays | Medium |
| 5 | Linked Lists | Easy |

Once users demonstrate proficiency in a topic,
they can choose to:

1. Advance to a new DSA concept.
2. Continue practicing problems of similar difficulty.

### Gamification

Planned features include:
- Experience points (XP)
- Daily practice streaks
- Achievement milestones
- Topic completion tracking
- Unlockable learning paths

### Coding Challenges

Users can practice LeetCode-style problems covering:

- Arrays
- Strings
- Hash Maps
- Two Pointers
- Sliding Window
- Linked Lists
- Trees
- Graphs
- Dynamic Programming
