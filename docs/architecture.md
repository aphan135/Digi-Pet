# Architecture

## Web

The React/TypeScript website owns the learning experience:

- Challenge screen
- Mock question data
- Attempt workspace
- Pet overlay component
- Dashboard and profile views

## Swift

The Swift app can act as a companion launcher:

- Pet home screen
- Daily quote or fact
- Study streak summary
- Link into the web challenge flow

## Future Backend

A backend can later store:

- User profile
- Question attempts
- XP and streaks
- Pet state
