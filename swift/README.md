# Digi-Pet Swift

Placeholder folder for the Swift companion app team.

Suggested areas:

- `App/` - App entry and routing.
- `Views/` - SwiftUI screens.
- `Models/` - Data models.
- `ViewModels/` - Presentation state.
- `Services/` - API and persistence services.
- `Assets.xcassets/` - Images, colors, and icons.
